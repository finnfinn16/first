# 番茄钟 🍅

一个基于 Electron 的 macOS 桌面番茄钟：小窗口 + 菜单栏倒计时。

## 运行

```bash
npm install
npm start
```

> 注：已通过 `.npmrc` 配置 Electron 二进制走 npmmirror 镜像下载，避免 GitHub 下载超时。

## 使用

- **开始 / 暂停 / 继续**：点中间的大按钮（或菜单栏「开始/暂停」）
- **重置**：↺ 重置当前阶段
- **跳过**：⏭ 跳过当前阶段（专注→短休息→专注）
- **置顶**：📌 让窗口悬浮在其他窗口之上
- **设置**：⚙️ 调整专注/休息时长、长休息间隔、是否自动开始下一阶段
- **关闭窗口**：✕ 只是隐藏到菜单栏，程序仍在运行；菜单栏「退出」才真正退出

## 特性

- 专注 25 分钟 → 短休息 5 分钟，每 4 个番茄后进入长休息 15 分钟（均可配置）
- 圆环进度动画，三种阶段不同配色（专注红 / 短休息绿 / 长休息蓝）
- 阶段结束自动系统通知 + 提示音
- 菜单栏实时显示剩余时间，右键可控制
- 今日完成的番茄数自动统计（按天归零）

## 目录结构

- `main.js` —— 主进程：计时器、窗口、菜单栏、通知、配置持久化
- `preload.js` —— 安全地暴露 IPC 接口给渲染进程
- `renderer/` —— 界面（HTML/CSS/JS）
- `scripts/gen-icon.js` —— 生成菜单栏番茄图标
